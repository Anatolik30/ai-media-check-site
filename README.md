# AI Media Check — сайт

Страницы для Google (экран входа через Google) и будущей публикации в Google Play:

- `index.html` — о приложении;
- `privacy.html` — политика конфиденциальности (русский и английский).

Публикуются через GitHub Pages: Settings → Pages → Source: «Deploy from a branch», ветка `main`,
папка `/ (root)`. Адрес: `https://anatolik30.github.io/ai-media-check-site/`.

Политика должна соответствовать тому, что на самом деле делают приложение (репозиторий APP),
сервер (FastAPI) и набор данных (BOT-Data): что хранится, сколько и где. Меняется поведение —
обновите политику и дату в ней.
